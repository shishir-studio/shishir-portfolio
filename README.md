# SHISHIR Portfolio (Next.js)
Run locally: `npm install` then `npm run dev` -> http://localhost:3000
Edit content: src/data/content.ts (text, stack) and src/data/contact.ts (links). Photo: public/images/shishir.jpg
Deploy: push to GitHub, then import the repo at vercel.com (free). Next.js needs Vercel/Netlify, not plain GitHub Pages.
